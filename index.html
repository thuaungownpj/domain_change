AdminPanel Domain အသစ် ထပ်ထည့်နည်း

Nginx Configuration • Multi-Subdomain Auto Command Generator

Domain Auto Configurator

အောက်တွင် လက်ရှိအသုံးပြုနေသော Domain အဟောင်းများနှင့် ထပ်ထည့်လိုသော Sub Domain အသစ်များကို အနည်းဆုံး (၁) ခုမှစ၍ စိတ်ကြိုက် ထပ်တိုး/ပြင်ဆင်နိုင်ပါသည်။ ရိုက်ထည့်လိုက်သည်နှင့် အောက်ပါ Command များအားလုံး အလိုအလျောက် ပြောင်းလဲသွားပါမည်။

လက်ရှိ Domain အဟောင်းများ (Old Domains)

ပထမဆုံး Domain အဟောင်း (#1) ကို Nginx config ဖိုင်အမည် (/etc/nginx/sites-available/...) အဖြစ် အသုံးပြုပါမည်။

ထပ်ထည့်မည့် Domain အသစ်များ (New Sub Domains)

ထပ်ထည့်ထားသမျှ Domain အသစ်အားလုံးအတွက် ping, sed နှင့် curl command များ အလိုအလျောက် တန်းစီထွက်လာပါမည်။

STEP 01 လက်ရှိ Server မှာ Domain တွေကို Nginx နဲ့ တွဲထားတာလား ဒါမှမဟုတ် Docker container ထဲကလားဆိုတာ အရင်စစ်ဆေးနည်း

bash - check sites-enabled
ls -l /etc/nginx/sites-enabled/

STEP 02 လက်ရှိ အသုံးပြုနေတဲ့ Nginx configuration ဖိုင်ကို စစ်ဆေးနည်း

bash - view nginx config

STEP 03 Server ပေါ်ကနေ DNS ချိတ်ဆက်မှု အခြေအနေကို စစ်ဆေးဖို့အတွက် Command

bash - ping new domains

STEP 04 မပြင်ခင် လက်ရှိ configuration ဖိုင်ကို အရေးပေါ်ပြန်ယူနိုင်အောင် backup အရင်လုပ်နည်း

bash - backup config

STEP 05 Nginx config ဖိုင်ထဲက server_name နေရာမှာ Domain အသစ်ထပ်ထည့်နည်း

bash - sed update server_name

STEP 06 ဖိုင်ထဲမှာ စာသားတွေ နေရာတကျ မှန်ကန်စွာ ဝင်သွားခြင်း ရှိ/မရှိ ပြန်လည်စစ်ဆေးနည်း

bash - verify server_name

STEP 07 Nginx configuration syntax အမှားအယွင်း ရှိ/မရှိ စစ်ဆေးရန်

bash - test nginx config
sudo nginx -t

STEP 08 Nginx configuration အသစ်ကို အသက်သွင်းရန်

bash - reload nginx
sudo systemctl reload nginx

STEP 09 Domain အသစ်များကနေ HTTPS ဖြင့် ကောင်းမွန်စွာ ချိတ်ဆက်အလုပ်လုပ်ခြင်း ရှိ/မရှိ စစ်ဆေးရန်

bash - curl https check
